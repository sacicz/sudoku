# Sudoku

A calm, fully offline sudoku for the Mudita Kompakt, designed for E Ink: black and white, no animations, no timer.

[![ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/J4V82A4UVG)

## What it can do

**Puzzles**
- Four levels: Easy, Medium, Hard and Expert, all open from the start
- Every puzzle has exactly one solution and never needs guessing
- The level comes from the techniques a puzzle needs, not just how many numbers it gives

**Playing**
- Notes that clear themselves when you enter a number
- Undo while a game is open
- Repeated numbers can be marked, and matching numbers highlighted; both can be turned off
- Every move is saved, and each level keeps its own game

**Languages:** Croatian, English, German, French, Spanish, Italian, Portuguese, Dutch, Polish, Czech

## Good to know
- No timer, points, streaks or statistics

## Privacy
Fully offline: the app has no internet permission and asks for no phone permissions.

## Install
Download the latest APK from [Releases](../../releases/latest) and install it on your Kompakt with Mudita Center.
